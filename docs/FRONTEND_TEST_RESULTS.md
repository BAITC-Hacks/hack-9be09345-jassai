Сквозное начало и завершение активности в новом интерфейсе подтверждено через настоящий API A на синтетической тестовой БД. Это отдельный прогон от preview и прежней проверки EV_GOOD ниже; реальный облачный AI в нём не проверялся. Браузерная проверка достижений после обновления main подтверждает включение/выключение и отсутствие ретроактивных XP; начисление новой награды проверено автоматическими тестами, а не отдельным браузерным выполнением после обновления.

Preview использует независимо вымышленные данные, явно помечен и не вызывает AI. Точная квитанция текущей сессии содержит цель на момент выполнения; реконструкция старой истории обозначена отдельно и использует текущую цель/каталог.
