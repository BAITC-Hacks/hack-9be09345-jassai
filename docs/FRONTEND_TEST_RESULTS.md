Сквозное начало и завершение активности в новом интерфейсе подтверждено через настоящий API A на синтетической тестовой БД. Это отдельный прогон от preview и прежней проверки EV_GOOD ниже; реальный облачный AI в нём не проверялся. Браузерная проверка достижений после обновления main подтверждает включение/выключение и отсутствие ретроактивных XP; начисление новой награды проверено автоматическими тестами, а не отдельным браузерным выполнением после обновления.

Preview использует независимо вымышленные данные, явно помечен и не вызывает AI. Точная квитанция текущей сессии содержит цель на момент выполнения; реконструкция старой истории обозначена отдельно и использует текущую цель/каталог.

## Предыдущая базовая проверка A + C, до редизайна

Эти результаты сохранены как предыдущий прогон, а не повторная проверка новой версии:

- `python -m pytest -q`: **38 passed**, одно предупреждение Starlette о deprecated httpx в TestClient. Это прежняя серверная версия; окончательный прогон после обновления main — 65 тестов выше.
- Среда: Python 3.13.15, зависимости из `pyproject.toml` в отдельной `.test-deps`. Это не проверка установки через `uv.lock`/launcher на чистой Windows и не проверка Python 3.12.14.
- A запускался на `127.0.0.1:8766` с отдельной синтетической SQLite БД вне публикуемых файлов, без параметра preview.

| Прежний браузерный сценарий | Результат |
|---|---|
| Вход/выход сотрудника и HR | Cookie и CSRF работали через браузер |
| Профиль, цель, история, имена навыков | Данные получены из API A |
| Начать и выполнить EV_GOOD | Создана запись участия; Architecture **2 → 4**, покрытие **40% → 80%**, история completed |
| Импорт неизвестного NEW_UI_JURY | Браузерная загрузка, validate valid=true, apply добавил профиль; он появился в списке и выборе аккаунта |
| HR и неподключённый AI | Серверные агрегаты отображались; отсутствие AI обозначалось явно |

Создание аккаунта проверялось тестами сервера/адаптером; отправка формы создания нового пароля в браузере не проверялась. Bootstrap проверялся тестами A/адаптера; настоящий браузерный мастер на чистой БД ещё не пройден.
