# Разговор со спутником и скорость

Текущий интерфейс — текстовый вопрос и всплывающее HTML-облако над местом модели A.
Голос, микрофон, распознавание речи и синтез речи в эту поставку не входят.

## Как ответы связаны с четырьмя задачами

| Задача | Что реализовано |
|---|---|
| Зачем активность и куда она ведёт | Цепочка «активность → точные уровни навыка → цель», объяснение и открытие прогноза из чата |
| Сделать рост видимым | Древо из фактических уровней, результат до/после, постоянные награды и сохранённая одежда |
| Понимать живой язык | Свободный вопрос получает потоковый ответ OpenAI или NVIDIA с контекстом текущего профиля; типовые вопросы разбираются локально |
| Не терять скорость | Локальные фактические ответы, один переиспользуемый HTTP-клиент, короткий контекст, до 400 выходных токенов, streaming, отмена, таймаут и кэш |

Локальный разбор ограничен понятными намерениями: конкретная активность/навык,
прогресс, награды, следующий шаг, короткое занятие. Он не выдаётся за LLM.
Для сложной формулировки нужен настроенный провайдер; при отсутствии подключения
отображается честное сообщение и остаются доступными кнопки профиля.
Качество понимания живой речи ещё требует оценки на реальных фразах пользователей.

## Настройка

OpenAI использует тот же `OPENAI_API_KEY`, который launcher B передаёт серверу.
Для отдельной модели разговора задаётся `OPENAI_COMPANION_MODEL`, иначе берётся
`OPENAI_MODEL`, затем текущая модель команды `gpt-6-luna`. Поддержка модели
зависит от доступа конкретного API-проекта. Ключи не вводятся в браузере и не
попадают в Git.

NVIDIA подключается на сервере через `NVIDIA_API_KEY`;
`NVIDIA_COMPANION_MODEL` по умолчанию `meta/llama-3.1-8b-instruct`.
Для выбора задайте `CAREERQUEST_COMPANION_PROVIDER=openai` или `nvidia`.
В режиме `auto` используется настроенный OpenAI, затем NVIDIA при отсутствии
ключа OpenAI. Автоматического повторного платного запроса после ошибки нет.
NVIDIA в этой поставке отвечает за разговор; основной подбор рекомендаций
по-прежнему использует модуль B.

Для временной NVIDIA-сессии в PowerShell можно ввести ключ скрыто и запустить
обычный launcher; значение существует только в окружении процесса:

```powershell
$cqNvidiaSecret = Read-Host 'NVIDIA API key' -AsSecureString
$cqNvidiaCredential = [pscredential]::new('nvidia', $cqNvidiaSecret)
$env:NVIDIA_API_KEY = $cqNvidiaCredential.GetNetworkCredential().Password
$env:CAREERQUEST_COMPANION_PROVIDER = 'nvidia'
try { .\launcher.cmd } finally {
    Remove-Item Env:NVIDIA_API_KEY -ErrorAction SilentlyContinue
    Remove-Variable cqNvidiaSecret,cqNvidiaCredential -ErrorAction SilentlyContinue
}
```

Это не настройка постоянного защищённого хранилища NVIDIA. Такой экран и общий
мониторинг балансов пока отсутствуют. Имеющиеся кредиты провайдеров не означают
гарантию количества запросов; локальные подсказки вообще не расходуют API.

## Контракт и ограничения

`POST /api/me/companion/chat` требует сессию сотрудника и CSRF, принимает
`{message, history:[{role,content}], event_id?, skill_id?}` и возвращает NDJSON:
`status`, `delta`, затем `done` либо `error`. Максимум 2000 символов вопроса,
6 сообщений контекста, 8000 символов сообщения истории. Роль `system` от клиента
не принимается. Выбранная активность всегда включается в ограниченный контекст.

Только собственный профиль: имя, ID и подразделение не передаются провайдеру.
Передаются навыки, цель, допустимые активности, правила наград и введённый текст.
Названия и сообщения считаются данными. Ответ AI отображается как простой текст,
без HTML, и помечается источником; он не начисляет навыки, не записывает на курс
и не надевает вещи. Прогноз и условия наград вычисляет сервер, а не модель.

Кэш до 128 ответов на 120 секунд разделён по сотруднику, фактам, истории,
сообщению и модели. Одновременно для одного сотрудника допускается один
внешний ответ. Общий бюджет ожидания 8 секунд, клиент отменяет через 10 секунд;
кнопка остановки и уход со страницы прерывают поток. Оборванный ответ не
помечается успешным и не кешируется. Провайдерские ошибки и ключи не выводятся.
История UI хранится в памяти страницы и очищается при выходе и смене цели.

## Что означает «быстро»

Надпись «Сейчас разберёмся» — реакция интерфейса, а не первый содержательный
ответ. UI измеряет время от отправки до первого `delta`. Сервер отдельно
возвращает время генерации. Реальные локальные HTTP-замеры приведены в
[COMPANION_PERFORMANCE.md](COMPANION_PERFORMANCE.md). Они не доказывают задержку
облачного API, работу на большом наборе данных или голосовую задержку.

Следующий этап: собрать 30–50 обезличенных разговорных запросов с опечатками,
смешением русского/казахского и ограничениями времени; сравнить обе модели по
верности фактам, полезности и p50/p95 первого содержательного текста.
Для будущего голоса измерять от конца речи до первого слышимого полезного ответа:
распознавание → понимание → синтез. Нужны прерывание пользователем, потоковое
распознавание, прогрев соединений и отдельный тест целевого p95 < 1 секунды.
