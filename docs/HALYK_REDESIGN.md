Основание: предоставленное пользователем Halyk_Career_Quest_UIUX_TZ.md от 23 сентября 2026. Встроено в существующий frontend; backend A и AI-интерфейс B сохраняют свои границы.

## Данные и смысл

- Текущие навыки и покрытие приходят с сервера. Числа из дизайн-ТЗ не становятся production fixtures.
- Прогноз — чистый расчёт на копии данных по правилам A. Его новые возможности не содержат действующей кнопки начала до фактического обновления профиля.
- Прогноз соблюдает max_level, общую шкалу0–5, prerequisites, роль/грейд, даты, mandatory и правила повторного прохождения.
- Показатель процентов обозначен как покрытие требований; изменение выражено в процентных пунктах.
- Точная квитанция завершения сохраняет исходную цель в текущей сессии. Восстановление старых записей помечается расчётом для текущей цели/каталога.
- HR-период фильтрует участие; не означает исторический срез всех сотрудников и навыков.
- HR «без цели» означает отсутствие эффективной цели по API. Автоматически предложенный следующий грейд считается эффективной целью; число всех невыбранных явных целей API отдельно не передаёт.
- Группы причин HR пересекаются; их суммы нельзя принимать за число уникальных сотрудников.
- Сохранены добавленные A в main 882a221 личные квесты, XP и значки. Их серверные правила не меняются; HR не получает доступ к личным достижениям. Четыре основных пункта навигации сохранены, достижения открываются с «Мой путь».

## Осознанные ограничения

- RU/KZ открывает статус локализации: русский доступен, казахский ещё не переведён.
- Уведомления показывают события текущей сессии, без вымышленного серверного центра уведомлений.
- «Забыли пароль» объясняет обращение к HR/администратору; backend сброса отсутствует.
- «Запомнить логин» хранит только логин, не пароль и не токен.
- Нет времени начала мероприятия, если источник содержит только дату.
- Нет настоящих API-балансов, недостоверных unlocks или вымышленных результатов обучения.
- LMS и внешняя регистрация на курс не подключены. Действия учитывают участие локально.
- Это рабочие HTML/CSS/JS-компоненты приложения. Отдельный Figma-файл не создавался.
- Launcher, реальные OpenAI/NVIDIA, ключи и качество AI остаются отдельной интеграцией B.

## Структура

`tokens.css` / `styles.css` — единая визуальная система; `icons.js` — локальные SVG; `views.js` — личный кабинет и overlays; `views-hr.js` — HR; `domain.js` — чистые прогнозы/история/фильтры; `backend.js` — адаптер API A; `app.js` — маршрутизация, формы и состояния.

Изображение входа и Manrope хранятся локально. Источники и лицензии: `frontend/assets/ASSET_SOURCES.md`. Фото иллюстративное, люди на нём не обозначены сотрудниками Halyk.

Проверки и ограничения реальных испытаний: `FRONTEND_TEST_RESULTS.md`.
