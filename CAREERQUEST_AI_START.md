# Career Quest — AI и API

Архив CareerQuest-AI-B-20260923.zip содержит текущий код приложения с облачным AI-чатом и рекомендациями, серверным API и интерфейсом. Зависимости включены как pyproject.toml и uv.lock; виртуальное окружение устанавливается отдельно.

Главные файлы: app/ai/chat.py, app/ai/provider.py, app/main.py, app/models.py, frontend/chat.js, frontend/chat.css. Контракт чата — docs/AI_CHAT.md.

Windows: распаковать весь архив, запустить launcher.cmd; при настройке AI указать действующий ключ скрытым вводом и модель gpt-4.1-mini. Linux/macOS после установки uv: uv sync --locked, затем uv run python -m app serve --ask-ai-key --model gpt-4.1-mini --port 8000.

Сотрудник открывает /#chat. API: POST /api/me/chat с message и history, авторизованной cookie-сессией и X-CSRF-Token. Ключ только на сервере, в браузере не нужен.

Ключ, база сотрудников, пароли и данные организаторов НЕ включены. На чистом запуске HR создаёт доступ и импортирует свой набор; прежние временные логины в архив не переносятся. Не заменяйте существующую базу: при переносе сохраните CAREERQUEST_DATA_DIR.

Это снимок работающего кода, а не обещание устранения замечаний аудита: детализация истории рекомендаций по навыкам пока не доработана, полный набор жюри не проверен, внешний OpenAI не является полностью внутренним контуром. Реальный Windows-запуск в текущей Linux-среде не проверялся.
