# Halyk Career Quest interface

The user explicitly selected the attached Halyk UI/UX specification on 2026-09-23. It replaces the previous dark-green career hero and the exploratory RPG concept. Mode: Operate.

## Direction

Calm light fintech/enterprise application. Background #F5F7F6, white surfaces, Halyk-family green for primary actions and navigation, orange attention and red error/critical states. Rounded 16–20px cards, subtle borders, 24px rhythm, desktop sidebar around236px, mobile bottom navigation.

## First viewport

Employee: page title, personal greeting, current→target role and honest coverage, then one dominant recommendation with concrete reasons and expected effects. Alternatives remain choices rather than a sequential plan. HR: differentiated help/goal categories, actionable causes and skill deficits.

## Components and behavior

One rounded stroke icon set, common buttons/fields/chips/progress/tables, centered goal dialog, right detail/forecast drawers, completion result. Keyboard focus and reduced motion are mandatory. Drawer/modal content scrolls while primary actions remain reachable. Forecast is visibly distinct from saved completion.

## Constraints

All displayed numbers use API data or labeled synthetic preview data. Do not hardcode the sample72%, Grade4, balances, course times or unlocks. Login photo is illustrative. Unavailable language, notification and account-recovery functionality must explain its status, not pretend to work. No external font/icon dependencies at runtime.

## Delivery

Implement directly in the existing static frontend under the supplied screen specification. Keep API contracts and role boundaries. Document unsupported infrastructure and inspect desktop/mobile once, fix defects in a batch, then verify changed surfaces.
